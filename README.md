# АПТАЙМ · Ночная смена

**Учебная игра-расследование на 90 минут** по теме «Механизм исключений. Блоки `try-catch-finally`. Иерархия исключений» (специальность ПОИТ, 3 курс, три бригады по 6 человек: `▲ TRY`, `⬡ CATCH`, `■ FINALLY`).

> Три бригады дежурят в ночной диспетчерской службы «Аптайм», расследуют вторжение в сервис продажи билетов «Партер» (`test/test`, `02:07–02:48`, выгрузка `0 байт`, оставлено `26 записей` с испорченными полями) и к `09:00` должны провести очередь из **1 240 человек**.

---

## Состав приложения и возможности

Приложение реализует полный комплект из 11 документов смены (`00`–`11`):

1. **Экран зала (Сцена проектора 62% / 38%)**:
   - **Слева (~62%) — Монитор**:
     - **Завязка (`03:00 → 03:20`)**: 4 интерактивные сцены («Вход», «Вскрытие», «Отбито», «Продолжение: АТАКИ ПРОДОЛЖАТСЯ») с дословным суфлёром на 19 реплик (124 слова ≤ 130 слов).
     - **Полигон «Партер» (`Program.cs`, `Booking.cs`, `Pricing.cs`, `Seats.cs`, `Promo.cs`)**: крупные номера строк (`21px+`), подсветка уязвимых мест, рукописные пометки («след человека»), 4 слота патчей (`1`–`4`) и **Живой запуск (`Enter`)** с тяжёлым физическим штампом `ПРОБИЛА` / `ОТБИТА`.
     - **Табло старта в `09:00` на 1 240 клеток**: сетка `40 × 31 = 1 240` человек в очереди. Каждая пробитая волна оставляет наглядную красную дыру ровно на **30 человек** (`1240 / 1210 / 1180 / 1150 / 1120`).
   - **Справа (~38%) — Вертикальная приборная панель**:
     - **Три бронеплиты бригад (`▲ TRY`, `⬡ CATCH`, `■ FINALLY`)**: различаются строго **формой клейма**, а не цветом; латунная шильда, чип роли в бою (`АТАКА` / `ЗАЩИТА` / `АРБИТР`), 4 лампы-предохранителя, очки кеглем `56 px`.
     - **Наряд-задание (на матовой бумаге со скошенным углом)**: точечно-матричный призыв `ВЫБЕРИ ПАТЧ`, моноширинная строка атаки `21 px`, награда `42 px`, подвал со сроком и ролями.
     - **Щит смены (`6/6`)**: 6 правил («Анатомия», «Механизм», «Перехват», «Порядок», «Гарантия», «Честность»). Пока щит не собран целиком, кнопка `СТАРТ 09:00` физически заблокирована.
     - **Блок времени `БВ-1`**: семисегментные индикаторы под стеклом (часы смены `03:00 → 09:00` и таймер такта, причём фаза `08:55 Пять минут до` идёт секунда в секунду с реальным временем), шкала с красной зоной, клавиши `Пуск/Пауза`, `+30 с`, `След. такт`, `След. фаза` и кнопка `Сброс` под откидным защитным колпаком.
2. **Клиент бригады**:
   - Поддержка всех 6 ролей (`Аналитик`, `Картёр`, `Чтец`, `Писарь`, `Докладчик`, `Арбитр`).
   - Трёхпольный бланк карты (`СТРОКА`, `ТИП`, `УТВЕРЖДЕНИЕ`) с автопроверкой по регламенту (обязательный номер строки, точный тип исключения вместо слова «Ошибка», одно утверждение, блокировка после отправки в текущем такте).
   - Карточка дословного чтения для Чтеца и Докладчика, кнопка `Апелляция (30 сек)`, пульт Писаря для ведения журнала смены и режим приглушения экранов во время доклада стоя.
3. **Панель арбитра**:
   - Сопоставление карт атаки и защиты рядом, живой запуск полигона, вынесение вердикта `ПРОБИЛА [Y]` / `ОТБИТА [N]` / `НЕ ПРИНЯТА`, генератор устной формулы для объявления стоя и кнопка `Найти пропуск [Q]` (`+1` очко арбитру).
4. **Панель ведущего**:
   - Управление всеми фазами 90-минутного урока и 6 тактами боя, корректировка очков с обязательной записью в журнал, штраф `−1 Подсказка из зала`, распределение ролей Боя 4 по рейтингу, переключение 4 миров («Партер», «Игровой сервер», «Доставка еды», «Регистратура») и 3 режимов (`ПОЛНЫЙ`, `РУЧНОЙ`, `АВТОНОМНЫЙ`).
5. **Печатный центр и Защита (`Протокол и Защита`)**:
   - Одностраничный **Протокол смены (A4)** с кнопкой печати (`Ctrl+P`).
   - **Раздатка «Шесть правил» (Щит смены A4)**.
   - Интерактивные **12 слайдов защиты (на 3 минуты)** с речью и ответами на вопросы комиссии.
   - **Домашнее задание трёх уровней** (Обязательный, Повышенный, Высокий).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Пуск / пауза таймера такта и фазы |
| `1`, `2`, `3`, `4` | Включить / выключить слот патча 1–4 на полигоне |
| `Enter` | Живой запуск полигона «Партер» |
| `Y` / `N` | Вердикт арбитра: `ПРОБИЛА` / `ОТБИТА` |
| `Q` | Зафиксировать найденный арбитром пропуск (`+1` очко) |
| `R` | Переключить на следующий такт боя |
| `Esc` | Открыть аварийное меню смены |

## Быстрый старт и команды

```bash
# Установка зависимостей
npm install

# Запуск сервера смены (WebSocket /ws + REST /api + клиент) в режиме разработки
npm run dev

# Проверка типов TypeScript
npm run typecheck

# Запуск автоматических тестов (Vitest)
npm test

# Сборка продакшен-бандла
npm run build
```
