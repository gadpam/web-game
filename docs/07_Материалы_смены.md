# 07 · Материалы смены

07 · Материалы смены
Всё, что нужно напечатать, показать или ввести в приложение: карты, протоколы, журнал, раздатка.

1. Карты: шаблон
Карта — один экран клиента, одна мысль.
┌──────────────────────────────────────────────┐
│  БРИГАДА  TRY        РОЛЬ  атакующий         │
├──────────────────────────────────────────────┤
│  СТРОКА      14                              │
│  ТИП         DivideByZeroException           │
│  УТВЕРЖДЕНИЕ                                 │
│  b приходит из ввода, проверки нет           │
├──────────────────────────────────────────────┤
│  [ ОТПРАВИТЬ ]            осталось 0:42      │
└──────────────────────────────────────────────┘
Три поля, не больше. Всё, что не влезает в три поля, — не карта, а рассуждение.

2. Комплект карт атаки
Атаки не выдаются готовыми — их пишут бригады. Ниже — эталонные формулировки: по ним
преподаватель проверяет, что карта написана по правилам, и по ним же настраивается
автопроверка клиента.
Бой 1. Перехват
Строка Тип Эталонная формулировка
12 FormatException place разбирается через
int.Parse, place приходит из
тела запроса без проверки
14 DivideByZeroException total / count, count приходит
из ввода, ноль не отсечён

Бой 2. Порядок
Строка Тип Формулировка
22–27 оба типа catch (Exception) стоит первым
и перекрывает catch
(FormatException)
22–27 проверка обработчик конкретного типа
после общего недостижим —
CS0160


Бой 3. Гарантия
Строка Тип Формулировка
41 ресурс соединение открывается до try,
при исключении не закрывается
41 finally закрытие в finally выполняется
и при return, и при падении

Бой 4. Честность
Строка Тип Формулировка
55 пустой catch catch { } — ошибка исчезает, 26
записей не попадают в отчёт
58 throw ex теряется исходный стек: throw;
сохраняет, throw ex; обнуляет

4. Журнал смены
Ведётся писарем в клиенте, выгружается в протокол.
Время Бой Кто Что заявлено Что проверено Результат
04:12 1 TRY строка 12,
FormatException
запуск: упало ПРОБИЛА
04:14 1 CATCH try вокруг Parse запуск: ОТБИТА

поймано
04:15 1 арбитр пропуск:
int.TryParse
дешевле
— +1

Правило журнала: запись должна позволять восстановить бой через сутки, без свидетелей.
«Обсудили и решили» — не запись.

5. Наряд-задание (экран)
Правая панель, блок под пластинами бригад.
ВЫБЕРИ ПАТЧ            ← крупно, матрица
14  int.Parse(place)   ← моно, строка атаки
+2  за пробитую        ← награда, крупная цифра
─────────────────────────────
срок 06:11 · роль атака · арбитр FINALLY
Требования: заголовок читается с последнего ряда; строка атаки — моноширинным; данные (строка,
тип) — только моно, матрица — только для крупной строки.

Формат: одна страница A4, крупные цифры, без украшений.


7. Раздатка «Шесть правил»
Печатается на A4 или показывается на экране в фазе «Пять минут до».
ЩИТ СМЕНЫ

1. АНАТОМИЯ
   Исключение — объект: тип, сообщение, адрес.

2. МЕХАНИЗМ
   try — зона. catch — перехват. finally — гарантия.

3. ПЕРЕХВАТ
   Обработчик стоит вокруг опасного места, а не рядом.

4. ПОРЯДОК
   От частного к общему. Иначе обработчик недостижим.

5. ГАРАНТИЯ
   finally выполняется всегда — и при return, и при падении.

6. ЧЕСТНОСТЬ
   Поймал — запиши. Проглотить значит скрыть.
Шрифт — крупный, без рамок и теней: раздатку читают с парты, а не рассматривают.

8. Что готовится к уроку
Материал Формат Количество

Панель арбитра приложение 1 ноутбук

Протокол смены печать после старта 1 на комиссию
