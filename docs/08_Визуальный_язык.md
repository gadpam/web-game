# 08 · Визуальный язык

08 · Визуальный язык
Правила, по которым собран интерфейс. Всё, что не описано здесь, в игру не попадает.

1. Принцип
Живость — не украшения, а физика.
Сгенерированный интерфейс узнаётся по трём признакам: всё одинаково гладкое, всё на одной
плоскости, ничего не имеет веса. Лечится это не декором, а тремя вещами: плоскости, свет,
материалы.
Приём Как делается
Плоскости панель лежит поверх фона, карточка — поверх
панели; у каждой своя глубина тени
Свет источник сверху-слева; тени вниз-вправо; у металла
— узкий блик по верхней кромке
Материалы три и только три: экран (гладкий, светящийся),
бумага (матовая, тёплая), бронеплита (тёмный
металл, винты, шлифовка)


2. Палитра

Фон сцены #050D16 подложка
Панель #08182A корпус приборов
Карточка #0C2138 рабочие поля
Текст основной #EAF2FA всё читаемое
Текст вторичный #A9C6DC пояснения
Подписи #8FB0C6 гравировка, единицы
Действие #4FC3F7 кнопки, активный такт
Инцидент #FF5D5D падение, пробила
Стабильно #35D0A0 отбито, пакет прошёл
Внимание #FFB020 предупреждение, латунь

Главное правило цвета:
Цвет означает состояние. Никогда — принадлежность.
Цвет не различает бригады. Бригады различаются формой: TRY — треугольник, CATCH —
шестиугольник, FINALLY — квадрат. Это защита от дальтонизма и от «игрушечности»: форма строже
цвета.

Размеры (минимум 13 px, ничего мельче):
Элемент Размер
Очки бригады 56 px
Заголовок наряда 50 px
Награда 42 px
Строка кода 25 px
Строка атаки (моно) 21 px

Правило: если элемент нельзя прочитать с последнего ряда — его либо увеличивают, либо
убирают. Третьего не дано.

4. Матричный шрифт
Точечная матрица используется только для одной строки — призыва к действию («ВЫБЕРИ ПАТЧ»).
На мелком кегле она нечитаема и превращается в грязь. Данные — всегда моноширинным, никогда
матрицей.

6. Четыре жеста
Их всего четыре, и каждый означает событие, а не украшает.
Жест Когда
Карта падает бригада отправила карту
Вердикт припечатывается арбитр объявил ПРОБИЛА / ОТБИТА
Жизнь сгорает потеряна запись в очереди, гаснет лампа
Плита встаёт фаза сменилась, поднялся новый прибор

Жест длится 0,2–0,4 секунды. Дольше — уже мультик.

7. Темы
Переключение — мгновенное, по клавише, без потери состояния, выбор запоминается.
Тема Когда
Ночная смена (тёмная) основная: проектор, тёмный класс
Светлый прибор яркий класс, слабый проектор, печать
Бумажный штаб опционально: полная замена материалов на бумагу

Темы меняют только CSS-переменные и вектор. Ни одна картинка не растрируется, ни одно
состояние не сбрасывается.

8. Чего не бывает
Запрещено Почему
градиентные «стеклянные» кнопки интерфейс, сгенерированный по шаблону
тени во все стороны нет источника света
иконки-эмодзи детский вид, разный рендер на машинах
скругления 20+ px «мобильное приложение», не прибор
цвет как признак команды ломает правило «цвет = состояние»
анимация дольше 0,4 с превращается в мультик
мелкий шрифт «для красоты» не читается с последнего ряда
